# 常见问题

## 为什么服务器显示「未检测」？

「已配置」不代表当前网络可达。点击服务器的「测试连接」会进行一次 SSH 登录检查；状态和测试时间只表示当前网页中最近一次测试结果，不是持续探测或可用性 SLA。

## 为什么操作记录里找不到 Agent 执行的命令？

SQLite 管理操作记录不会保存 Shell 命令正文或输出。这样可降低敏感数据暴露风险，但也意味着不能将其视作完整命令审计平台。

## 我已经添加服务器，为什么 AI 连不上？

检查：MCP URL 是公开的可信 HTTPS 地址；客户端成功完成 OAuth 授权或配置静态 Token；主机地址、端口、登录用户和认证文件在 **SSH-MCP 服务端** 可访问；`known_hosts` 已核验。先在控制台测试 SSH 连接，再根据 [客户端接入](clients.md) 验证 `list_servers`。

## 如何重置管理员密码？

使用服务账户在主机上执行 `ssh-mcp set-admin-password`，传入与部署时一致的配置和数据库路径。具体命令见 [控制台文档](console.md)。不要将密码写在命令参数或 Issue 中。

## OAuth 可以让不同客户端访问不同的服务器吗？

目前不能。一个实例面向一个可信操作者，已授权客户端共享配置的服务器和权限；没有多用户 RBAC 或逐服务器授权。部署前请为各目标 SSH 账户落实最小权限。

## 浏览器主题在哪里设置？

顶部的太阳/月亮按钮可切换浅色和深色；选择保存在当前浏览器本地。首次访问遵循系统的颜色偏好。

## 如何备份、更新和回滚？

备份数据库、运行配置、凭据文件和身份数据库；版本升级前阅读 [部署文档](deployment.md) 和 [更新记录](../CHANGELOG.md)。SQLite 不保存正在运行的 SSH 会话，重启不会恢复这些会话。

## 问题反馈应该提供什么？

提供版本、复现步骤、预期与实际行为、部署方式、已脱敏的错误消息和测试结果。不要上传 Token、私钥、管理员初始化链接、生产目标真实 IP 或远程命令输出。发现安全漏洞时按 [安全说明](../SECURITY.md) 私下反馈。
